Rclone backup

Rclone backup is a personal, non-commercial tool used by a single person (Miloš Vích) to store encrypted backups of his own files in his own Google Drive.

It uses rclone and restic with the Google Drive scope drive.file, so it can only see files that it created itself. It is not offered to other users.
